# Deletion Manifest — Flux (future Zairenkai)

Nothing may be deleted from this repository unless it is listed below with every field filled and
every condition of the Repository Data Preservation Lock proven:

1. proven obsolete; 2. no source, build, CI, test or runtime reference; 3. no migration needs it;
4. no historical/evidence value; 5. replacement exists where required and tests prove it;
6. recorded here. If any condition is unknown, the answer is **do not delete**.

"Can be regenerated" is not a reason. Runtime telemetry retention (7 days, device side) never
applies to repository files.
