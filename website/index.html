Yang dilakukan Flux

Setiap perubahan disimpan dulu lalu dikembalikan persis seperti semula begitu kamu keluar dari game.

Profil yang mengenali game

Performance saat game terbuka, Balance saat dipakai biasa, Powersave saat hemat baterai. Pindah sendiri tanpa perlu dibuka.

Thread render di core cepat

Thread render Unity, Unreal dan GL dipindah ke core tercepat dengan prioritas tinggi. Susunan core dibaca dari kernel, jadi cocok untuk 4+4, 1+3+4 maupun 2+6.

Performance Lite saat panas

Membaca sisa ruang termal Android, status thermal dan suhu CPU. Saat HP terlalu panas, profil turun ke Lite lalu naik lagi setelah dingin.

Refresh rate mengikuti game

Memilih mode layar terkecil yang masih menampilkan semua frame game, misalnya 90 Hz untuk game 90 FPS di panel 120 Hz.

Aturan per chipset

Chip yang dikenal cepat panas (Snapdragon 888, 8 Gen 1, Parrot, Exynos 2100/2200, Dimensity 9000) otomatis mendapat batas yang lebih aman.

Statistik sesi

FPS rata-rata, 1% low, drop, stabilitas dan suhu dicatat per sesi dari frame game itu sendiri, lengkap dengan grafik di WebUI.

Store

Cara memasang

  1. 1

    Unduh zip

    Pilih Universal kalau ragu. arm64 untuk ROM 64-bit, arm untuk ROM 32-bit.

  2. 2

    Pasang di root manager

    Magisk, KernelSU / KernelSU-Next atau APatch: Modul → Instal dari penyimpanan.

  3. 3

    Reboot dan buka WebUI

    Atur game, profil dan tweak dari WebUI modul. HiCo Thermal dipasang setelah Flux.
